# "Signal" (60s, 32 bars at 128 BPM)

**Earn attention; don't beg for it.** One idea, few words, a beautiful object, precise timing, and silence
used as a tool.

## The idea

**Randomness, given intention.** Thirty thousand points of light, each on its own seeded random path: the
agents' work. Individually random, collectively a river. When the agents stop, every point freezes exactly
where it was. When Looper takes over, the same points gather into one ring that never stops.

## Rules

- **The work drives the image.** Positions are a function of *work-time*, which only advances while agents run.
  A Stop is therefore a true freeze of the whole world, in sync with the tape-stop in the score.
- **The camera is you.** You are still awake while the work is frozen, so the camera drifts through the
  stopped points (bullet time).
- **Colour means something.** Cold white and dead black while you are the loop; a lavender night only after
  Looper closes it.
- **The product is revealed by light, not by a fade.** The orb is always there in the dark; a studio light
  sweep discovers it, first as a macro on glass, then whole.
- **Words land once and never move.** "Every / few / minutes." each land on a freeze, pre-laid-out so
  nothing reflows. The only machine voice is `continue? y`.
- **Rhymes.** The river's streaks return as the ring's streaks. The first image is one point of light;
  the last is every point, looping.
