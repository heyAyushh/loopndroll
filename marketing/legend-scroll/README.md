# The Legend of the Looper · 循環

A 140-second legend told the way handscrolls and shadow-play prologues tell
them: a scroll is untied by candlelight, unrolled right to left, and the
painting wakes into a living ink world where jointed shadow puppets act out
Odysseus's voyage — with Looper keeping the work moving at home the whole time.
At the end it flattens back into paper, rolls up, and the red cord ties itself
into a loop.

Everything is code. No footage, no stock audio, no animation framework.

| File | Role |
| --- | --- |
| `core.js` | Palette, maths, deterministic noise, path and glow helpers. |
| `ink.js` | Xuan paper, pressure brush with flying-white, pre-blurred mountain ranges, mist, ruyi clouds, haishui sea, lotus, trees, the storm dragon, lightning, calligraphy, cinnabar seals. |
| `puppets.js` | Piying shadow puppets: translucent leather, lattice cut-outs, open faces, riveted joints, water sleeves, control rods; sirens; paper cranes. |
| `props.js` | Ink laptop with jade session lights, phone, jade bi discs, loom, pavilion, lanterns, galley, bow, the physical scroll, lacquer table, candle, incense. |
| `story.js` | The scroll's layout (read right to left), beats cut to the narration, camera keyframes, and the thirteen painted stations. |
| `renderer.js` | Multiplane compositor: table ↔ living painting, unroll/roll-up clipping, light, darkness, silence, motes, narration inscriptions, title. |
| `music.js` | Sample-level score: Karplus–Strong guzheng, dizi, erhu, pads, taiko, tam-tam, opera gong, temple bell, jade chimes, foley. |
| `narration.js` | Generated by `tools/make-narration.mjs` (neural TTS + measured timings). Picture beats derive from it. |
| `render.mjs` | Local HTTP server → headless Chrome → ordered frames → ffmpeg; mixes the voice chain over the ducked score. |

## Rules the picture obeys

- Ink on xuan paper. **Cinnabar** belongs only to the red thread and seals;
  **jade** only to work that is running; gold is light.
- The story reads right to left, as a handscroll does.
- Every event — picture or sound — is timed from the narration's measured
  clip starts, so the edit follows the voice.

## Run

```bash
cd marketing/legend-scroll
PUPPETEER_SKIP_DOWNLOAD=1 npm install
bash tools/fetch-fonts.sh fonts      # OFL fonts from google/fonts (not committed)
node tools/make-narration.mjs     # regenerate voice clips + narration.js (needs uvx / network)
python3 -m http.server 8080       # then open http://localhost:8080 for the live preview
npm run stills                    # review PNGs → out/stills/
npm run render                    # 1080p60 MP4 → out/legend-of-the-looper.mp4
npm run mix                       # score + narration only → out/mix.wav
```

Requires Google Chrome (override with `CHROME_PATH`) and `ffmpeg`.
