# The Butlers Who Would Not Proceed — brief

Built with the workflow from [motion-video-kit / business-motion-film](https://github.com/echris6/motion-video-kit):
brief → storyboard → code-built deterministic motion → measured checks → independent critic rounds.

| Field | Value |
| --- | --- |
| Business | Looper — a Mac app that keeps AI coding agents (Codex, Claude Code, Cursor) moving after they stop. |
| Buyer | Developers who babysit coding agents. |
| Viewer's problem | Agents stop before the work is done, or stop to ask permission, so the developer can never leave the chair. |
| Single action | Visit **looper.fyi**. |
| What we claim (from the product owner's brief) | Looper runs on your Mac; checks whether agents are really done; sends them back to work when tests fail; sends their genuine questions to your phone, anywhere. |
| Never claim | Numbers, savings, ratings, testimonials, supported agents beyond the three named. |
| Tone | Deadpan Wes Anderson-style comedy: symmetry, pastel palette, Futura, chapter cards, snap zooms, whip pans, dry narration. |
| Length | 75 s. |
| Aspect ratios | 1920×1080 landscape and 1080×1920 portrait, from one source. |
| Assets | No real footage. Every frame is code-drawn SVG/HTML (no AI imagery). Voices: macOS `say` (Daniel narrator, Samantha friend). Music: "Secret Garden" by Eugenio Mininni, Mixkit Stock Music Free License. |
| Mute test | Every spoken line is burned in as a subtitle; the end card states the product, the promise and the URL. |
